# Demo food images

The food images in this folder (`shakshuka.jpg`, `shakshuka-tall.jpg`, `harira.jpg`,
`salad.jpg`, `tagine.jpg`, `msemen.jpg`, `cookies.jpg`) were cropped from concept artwork
supplied by the repository owner (DivProGamez) for this demo. Overlaid UI elements (heart
icons, captions) were removed by inpainting, and the crops were upscaled 2x (Lanczos) and
saved as JPEG. `ambient.jpg` is a heavily blurred collage of those same crops, used as the
stage background.

They are demo content for `examples/tv-demo` only and are not part of the DPadBridge SDK
(`src/`, `dist/`), which has no image or asset dependencies. If you build on this demo,
replace them with images you have the rights to use.
